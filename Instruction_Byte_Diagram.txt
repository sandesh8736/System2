================================================================================
INSTRUCTION BYTE DIAGRAM
================================================================================

+------------+------------+------------+---------------------+---------------------+
| Opcode     | ModR/M     | SIB        | Displacement        | Immediate           |
+------------+------------+------------+---------------------+---------------------+
| 1-, 2-, or | 1 byte     | 1 byte     | Address displacement| Immediate data of   |
| 3-byte     | (if        | (if        | of 1, 2, or 4 bytes | 1, 2, or 4 bytes    |
| opcode     | required)  | required)  | or none              | or none              |
+------------+------------+------------+---------------------+---------------------+

-- OPCODE: A primary opcode can be 1, 2, or 3 bytes in length.
-- MOD R/M: Takes total 1 byte.

The Mod r/m byte is:

+---------+-------------+---------+
| Mod     | REG/OPCODE  | R/M     |
+---------+-------------+---------+
| 2 bits  | 3 bits      | 3 bits  |
+---------+-------------+---------+

-- SIB: Takes total 1 byte.

The SIB byte will be:

+---------+---------+---------+
| Scale   | Index   | Base    |
+---------+---------+---------+
| 2 bits  | 3 bits  | 3 bits  |
+---------+---------+---------+

-- Displacement: If a displacement is required, it can be 1, 2, or 4 bytes.
-- Immediate: An immediate operand can be 1, 2 or 4 bytes.

Notes:
  * This is a practical subset for 32-bit x86 mode, not the complete x86 ISA.
  * Register/Memory describe explicit operands: 1 = required, 0 = absent,
    1/0 = optional depending on the selected register-or-memory operand.
    Implicit registers such as EAX/EDX, ESP, and EFLAGS are not counted.
  * r8/r32 = register; r/m8, r/m16, r/m32 = register or memory of that size.
    m = memory addressing expression (LEA calculates its address).
  * /r = ModR/M includes a register operand; /0 through /7 = fixed opcode
    extension in the ModR/M REG field. +rb/+rd adds the register code.
  * Opcodes such as 0FAF contain two bytes: 0F AF.
  * imm8 with opcode 83 or PUSH 6A is sign-extended to 32 bits.
    Shift/rotate count 1 is implicit with D1 (no immediate byte).
  * rel8/rel32 is a signed offset from the end of the instruction.
    Multi-byte immediate values and offsets are stored little-endian.
  * SAL and SHL are aliases; JC/JB, JNC/JAE, LOOPZ/LOOPE, and
    LOOPNZ/LOOPNE are aliases. JECXZ assumes 32-bit address size.
  * DEV was a typo; the unsigned division mnemonic is DIV.
  * Example: xor ecx,ecx can encode as 31 C9; cmp byte[esi],0 as 80 3E 00.
    Pass 1 of Assigement_4.cpp saves ASCII values of opcode digits; pass 2
    decodes them and builds these machine bytes. INC 40+rd and DEC 48+rd
    are compact forms available in 32-bit mode (not in 64-bit mode).
  * Reference: Intel 64 and IA-32 Architectures Software Developer's Manual,
    Volume 2 (Instruction Set Reference):
    https://www.intel.com/content/www/us/en/developer/articles/technical/intel-sdm.html
